# Tile usage guidelines

Tiles are for emphasis, not explanation.

Use a tile when the content works as a short visual moment: a hero image, category preview, proof point, stat, quote, CTA, or navigation choice.

Use an editorial section, list, table, FAQ, or prose block when the content teaches, explains, compares, or helps a buyer make a decision.

## Good tile uses

- One strong idea
- One short headline
- Optional single-sentence support copy
- Image-led category previews
- Primary CTA moments
- Stats and proof points
- Short quotes
- Visual rhythm breaks between longer sections

## Poor tile uses

- Multi-sentence buyer education
- Policy explanations
- Delivery rules that need context
- Product comparison copy
- Material guidance that needs examples
- Storytelling that should be read in order
- Any tile where the copy relies on truncation to fit

## Copy limits

A tile title should read at a glance.

A tile body should clarify the title, not carry the full message.

If the body needs more than one short sentence, move the content into an editorial or list section and use the tile only as a pointer.

## Layout rule

Do not stack multiple TileScreen sections back-to-back when the user is trying to read guidance.

TileScreen is best for page heroes, featured image modules, product/category previews, and high-impact proof/CTA breaks.

Editorial sections are best for the main buying path.

## BTY-specific rule

For Buy The Yard, the useful buying flow is:

1. What are you fixing?
2. Which material probably fits?
3. How should you measure it?
4. What should Abby confirm?
5. Pickup or delivery?

That flow should usually be written as readable guidance, not tiled into fragments.
